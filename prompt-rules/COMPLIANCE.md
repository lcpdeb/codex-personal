# COMPLIANCE：合规材料专项规则

本规则适用于法律、金融、监管、政策和审计材料，由上级 `../AGENTS.md` 按任务范围加载。

- 模式：保真模式用于转录、抽取和结构化录入；分析模式用于摘要、比较和解释；修订模式用于改写、批注和红线比较；模式改变结构或证据要求时由用户确认。
- 来源：记录名称、版本、发布日期、适用日期、辖区及页码或条款。
- 时效：现行法律、监管要求、市场数据和费率使用当前官方权威来源，历史材料按其明确版本使用。
- 冲突：来源冲突或关键页面、附件、脚注缺失时报告影响并停止相关结论。
- 保真：保留顺序、编号、字段、表格、单位、币种、日期和脚注，疑似错误保留原值并单独标记。
- 派生内容：OCR 和抽取结果属于派生产物，版式承载含义时以原始页面和视觉核对为准。
- 分析：区分来源事实、分析判断、未验证假设和责任主体决定，并让关键结论可追溯。
- 解释：先用通俗语言陈述实际影响，再给出原术语、适用条件和边界；一般信息不能写成针对特定主体的确定性专业结论。
- 修订：只改变授权范围，实质变化记录原文、修改、原因和影响。
- 数字：金额、百分比、日期、数量、汇率和单位逐项核对；计算记录输入、单位、公式、舍入和来源，批量计算由确定性脚本执行并校验分项与合计。
- 差异：缺失数字和无法闭合的差异保留并报告。
- 敏感信息：只处理任务所需敏感信息，禁止发送到未经授权的外部服务。
- 验证：完成前检查来源版本、适用范围、章节与附件完整性、名称与数字、引用位置、计算闭合及事实与判断的区分，无法读取或未核对的区域明确标记。
