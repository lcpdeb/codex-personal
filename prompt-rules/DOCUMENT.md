# DOCUMENT：文档与表格专项规则

本文件由上级 `../AGENTS.md` 按任务范围加载。当前规范适用于将数据整理到 Excel，以及创建、修改和交付 Excel 文件，包括数据清单、台账、计算表、统计分析和报告。

通用任务契约、授权、事实依据和工具使用遵循上级规则。以下内容作为默认规范，具体用途、已有契约和用户明确要求优先；按实际任务选择需要的表格、汇总和图表。

## 内容与数据

- 按数据本身的关系组织 sheet 和表格，分类清楚，便于查找、筛选和比较。
- 最终文件直接说明当前数据、条件、结果和必要限制，清理制作过程说明、版本替换记录、排版占位文字及写给制表者的指令。
- 批注和额外说明列应有明确的阅读价值，避免为了说明内部制作过程而自行添加；已在独立栏目展示的信息，避免在其他说明中无意义地重复。
- 数值、日期、百分比等使用正确的单元格类型，便于计算、排序和筛选。
- 同类数据采用统一格式和小数位数；计算和判定使用完整精度，显示精度按阅读需要设置。
- 区分零值、缺失值和不适用；缺失数据使用明确标记。
- 原始数据、汇总数据、计算结果和文字说明按实际需求安排，保留来源及必要的计算依据，维护原始数据、计算结果、图表和结论之间的来源关系。
- 保留来源中指标的完整含义。扣除组成项、重新归一化或改变比较口径前，说明目的及影响，按已确认要求执行。
- 区分原始输入、转换后实际采用值、计算结果和最终显示值，说明影响判断的估算、舍入、截断及上限处理。
- 已确认排除或停用的项目，从统计、派生计算、隐藏汇总、图表和结论中同步排除。
- 根据对象类型展示实际生效的参数，说明含义和单位，省略未使用的默认字段。
- 数据区结构规整，每行、每列的含义一致；合并单元格用于标题和说明区域。
- 修改已有 Excel 时，保留已确认需要的数据、公式、图表及其他功能。

## 分析与结论

- 结论型报告先给推荐结果和理由，再展示数据依据；结合实际收益、结果变化、约束满足情况和主要代价，明确推荐成立的条件，减少重复文字。
- 比较采用一致的统计对象、范围和基准；均值、范围、比例、差值及聚合方法应有明确口径。异常记录明显影响结论时，说明具体数值及其影响。
- 总体结论保留对象之间会影响选择的重要差异，避免只用一个整体统计量概括全部对象。
- 可接受范围采用已确认的业务标准；尚未约定时，说明推荐采用的取舍。
- 指标的满足条件和优劣方向依据业务定义确定，包括上下限和边界条件。

## 表头与说明

- 表头使用读者能理解的名称，准确表达指标、单位和必要限定，避免程序简写或含混名称。
- 比较基准、比例分母及时间范围说明清楚，例如总耗时、阶段累计耗时和单次耗时分别命名。
- 共用格式和统计说明集中放在表格附近，位置清楚，避免在多个表头重复堆叠；同义表头和单位采用统一写法。

## 字体与对齐

| 内容 | 默认格式 |
|---|---|
| 普通文字、表头、数据 | 微软雅黑（Microsoft YaHei），11号 |
| 主标题、章节标题 | 微软雅黑，12号，加粗 |
| 图表标题 | 微软雅黑，12号，加粗 |
| 图表坐标轴标题、刻度、图例 | 微软雅黑，10号 |

- 单元格内容默认水平居中、垂直居中，标题栏同样居中。
- 长文本适当换行，行高保证内容完整显示。
- 颜色和加粗用于区分层次、强调重点，同类内容保持一致。
- 所有 sheet 保持无冻结窗格。

## 列宽与布局

- 用于直接比较的模式、方案或版本，采用对应的栏目、指标、表头和统计口径；确有差异的内容明确说明。总体汇总与对象明细沿用一致的比较结构。
- 需要左右并列时，对应内容逐项对齐，控制列宽和中间空白，方便直接对照。
- 核对同名指标的实际定义和参数，保留足以区分不同项目的标识。
- 列宽兼顾完整显示与整体阅读，并保留少量边距；短表头优先单行，较长表头合理换行，避免单纯为保持单行而把表格拉得过宽。同一列在不同表格中共用时，兼顾各处内容。
- 标题栏、表头和数据区的左右边界对应一致；清理无内容区域残留的底色、边框和多余样式。处理空白区域前，核对是否放有图表、公式或其他有效内容。
- 行高、表格间距和标题区域协调，保证文字完整显示，区域之间保持清晰间距。
- 数据量较大时，提供适当的筛选功能；表格保持方便排序和计算的结构。

## 图表

- 使用 Excel 原生图表，关联单元格数据，支持编辑。
- 根据数据关系和已确认要求选择图表类型及直线、平滑曲线等表现方式，表达比较、趋势、分布或构成。
- 对应比较的图表，核对指标选择、数据系列和统计口径，使读者能够比较同一含义的数据。
- 标题包含足以识别对象、指标及必要统计口径的信息；坐标轴名称、单位和图例清晰准确。
- 图表标题相对绘图区居中；横轴、纵轴标题分别相对对应坐标轴居中。
- 标题、坐标轴、刻度和图例之间保留距离，各区域完整显示，互不重叠。
- 图表尺寸适中，同类图表统一图例名称、顺序、位置、配色、线宽、数据点、字体、尺寸和数值格式。
- 数据标签按阅读需要添加，位置清楚、精度适当，避免拥挤。
- 图表放在对应数据附近，便于核对。
- 后续调整保留已经确认有效的显示设置。

## 检查与交付

- 用户要求样例时，样例准确体现拟采用的内容与排版，确认后按授权范围应用。
- 用户指出共性问题后，按已确认范围检查全部相关 sheet、表头、标题、数据区及图表。
- 核对数据完整性、单位、单元格类型、数值格式、公式和引用关系。
- 数据范围、表格结构或计算口径变化时，同步检查隐藏数据、公式、图表、汇总和结论。
- 核对文字显示、对齐、列宽、行高、无冻结设置和图表排版。
- 核对文件结构、绘图对象编号和关系引用；生成或转换图表时，每个绘图锚点对应一个有效绘图对象。
- 在具备相应工具和授权时实际打开文件，确认无修复提示，并检查文字布局、图表可见性及常用缩放比例下的表现；文件结构核查与实际显示核查分别报告。
- 已授权的小幅修改直接更新指定文件，避免反复生成未经要求的备份副本。
- 清楚说明文件位置、整理范围及未完成的检查。
