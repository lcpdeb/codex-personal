# POWERPOINT：演示文稿专项规则

本文件由上级 `../AGENTS.md` 按任务范围加载。当前规范适用于创建、修改、检查和交付 PowerPoint 演示文稿。

通用任务契约、授权、事实依据和工具使用遵循上级规则。以下内容作为默认规范，具体用途、已有契约和用户明确要求优先。

- 以推荐或决策为目的的演示文稿，应让推荐结论与支持它的数据对应。整体建议结合整体结果说明；使用单个案例时，说明该案例展示的具体情况及其在整体结论中的作用。
- 需要比较多个方案、档位或模式时，按照一致的基准、单位和统计口径组织数据，并展示用户要求比较的全部项目。需要说明数据分布时，根据问题选择范围、中位数、分位数或其他统计量，并清楚标注各统计量的含义。
- 选择能让读者直接比较的数据呈现方式；同一页或相邻页面中含义对应的表格和图表，采用协调的结构和样式。图形和数据分别编辑时，交付时说明数据修改后如何同步图形。
- 根据页面内容调整标题、图表、表格的尺寸和位置，保持信息层级清晰并合理利用页面空间。用户已确认完成的事项按当前状态表达；页面中的说明、来源和后续事项按该交付物的要求安排。

- 用户提供模板时，先查看模板的封面、母版、版式、字体、配色和标识，再根据内容选用对应版式；封面和内容页均遵循已确认的模板样式。
- 用户未提供模板时，使用 `documents/powerpoint/default.pptx` 作为默认模板。该路径相对于本 `POWERPOINT.md` 所在目录解析。用户提供的模板和明确指定的样式要求优先。
- 用户要求先看样页时，样页应体现最终拟采用的模板样式、内容组织和可编辑方式；确认后再用于整份演示文稿。
- 按要求保留文字、图形、表格和图表的可编辑性。使用可编辑图表时，图表展示值与其关联数据保持一致。
- 复用或精简模板时，保留当前文件使用的母版、版式、主题、字体设置、标识及其依赖资源。删除对象或页面后，同步检查动画、媒体、链接和其他关联引用，使每个保留的引用都有有效目标。
- 控制最终文件只携带成品需要的模板资源；检查资源之间的依赖，保持已确认的样式和功能。
- 交付前，根据目标平台和应用检查文件错误：核对文件格式、母版和版式关系、图表及其数据、媒体与动画引用，并处理检查发现的问题，避免用户打开文件时出现错误提示。
- 结合目标平台可用的工具检查文件结构和对象之间的实际引用；在具备相应工具和授权时，使用目标应用打开成品，检查修复提示、封面、文字、图表和主要布局。分别报告已完成的检查；无法执行的检查说明具体缺口。
